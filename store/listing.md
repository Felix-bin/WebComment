## 商品详情（Store listing）

**名称**（取自 manifest，最长 75 字符）

```
WebComment 网页批注
```

**摘要**（取自 manifest 的 description，最长 132 字符）

```
在任意网页上高亮文字、添加批注，再次打开时自动恢复。
```

**类别**：工具（Tools）　**语言**：中文（简体）

**详细说明**

```
WebComment 让你像在纸上一样阅读网页：划线、写批注，下次打开同一网页时自动恢复。

【高亮】
选中网页上的任意文字，弹出的工具栏中点一下色块即可高亮，支持 5 种颜色，可跨段落、跨列表和表格。

【批注】
点「批注」写下你的想法，边写边自动保存。点击已高亮的文字随时修改颜色、编辑或删除。

【自动恢复】
重新打开网页时，高亮和批注会自动回到原位。即使网页内容有改动、文字位置发生变化，也能通过上下文重新找到原文；对延迟加载的内容和单页应用（SPA）同样有效。

【集中管理】
· 点击扩展图标，查看当前网页的全部笔记，点一下跳转到原文
· 「全部笔记」页面汇总所有网页的笔记，支持搜索、按颜色筛选、编辑
· 一键导出 Markdown，方便放进 Obsidian、Notion 等笔记软件
· 支持 JSON 备份与导入

【快捷操作】
· 右键菜单：高亮选中文字 / 高亮并添加批注
· 快捷键：Alt+Shift+H 高亮，Alt+Shift+N 批注

【隐私】
所有数据只保存在你的浏览器本地，不上传任何服务器，无统计、无广告、无追踪。
开源地址：https://github.com/Felix-bin/WebComment
```

| 用途 | 文件 | 尺寸 |

## 隐私权规范（Privacy practices）

**单一用途说明**

```
在网页上高亮文字并添加批注，并在用户再次访问该网页时自动恢复这些高亮和批注。
```

**权限理由**

| 权限 | 理由（直接粘贴） |
| --- | --- |
| `storage` | 在本地保存用户创建的高亮、批注和设置。 |
| `unlimitedStorage` | 用户可能在大量网页上积累笔记，避免超出默认 10MB 存储上限导致笔记无法保存。 |
| `contextMenus` | 提供右键菜单「高亮选中文字」「高亮并添加批注」「打开批注管理」。 |
| `activeTab` | 在弹出窗口中读取当前标签页的地址，以列出该网页的笔记并跳转到对应位置。 |
| `favicon` | 在「全部笔记」页面中显示各网页的站点图标，便于识别。 |
| 主机权限（`http://*/*`、`https://*/*`、`file:///*` 的内容脚本） | 扩展的核心功能是在用户访问的任意网页上高亮文字，并在再次打开网页时自动恢复高亮，因此需要在所有网页上运行内容脚本。网页内容只在本地处理，不会被收集或上传。 |

**是否使用远程代码**：否，所有代码都打包在扩展内。

**数据使用**：不勾选任何数据类型（扩展不收集、不传输任何用户数据，数据仅保存在本地）。然后勾选全部三项承诺：
- 不会出于已获批准的用途之外的目的向第三方出售或传输用户数据
- 不会为实现与商品单一用途无关的目的而使用或转移用户数据
- 不会为确定信用度或实现贷款而使用或转移用户数据
